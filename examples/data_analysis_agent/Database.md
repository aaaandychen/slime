
# DataAgent demo_sales 数据库文档

## 概述

`demo_sales` 是一个模拟的零售业务数据库，包含 7 张表，覆盖商品、订单、客户、营销、退货、流量、供应商等业务域。数据库运行在 MariaDB 上，独立于 DataAgent 的 H2 业务库。

## 环境信息

- **数据库**: MariaDB 10.11
- **数据库名**: demo_sales
- **字符集**: utf8mb4
- **连接方式**: `mysql -u root demo_sales`

## 表结构

### 1. products（商品表）

| 字段 | 类型 | 说明 |
|------|------|------|
| product_id | INT PK | 商品ID |
| name | VARCHAR(100) | 商品名称 |
| category | VARCHAR(50) | 品类：电子产品/运动鞋服/家用电器/美妆护肤/酒类 |
| price | DECIMAL(10,2) | 售价 |
| cost | DECIMAL(10,2) | 成本 |
| stock | INT | 库存数量 |
| supplier_id | INT | 供应商ID |

**数据量**: 15 行

### 2. orders（订单表）

| 字段 | 类型 | 说明 |
|------|------|------|
| order_id | INT PK | 订单ID |
| product_id | INT FK | 商品ID |
| customer_name | VARCHAR(50) | 客户名称 |
| quantity | INT | 数量 |
| unit_price | DECIMAL(10,2) | 下单时单价 |
| order_date | DATE | 订单日期 |
| region | VARCHAR(20) | 区域：华东/华北/华南 |
| channel | VARCHAR(20) | 渠道：线上/线下 |

**数据量**: 100 行（2026年1-9月）

### 3. customers（客户表）

| 字段 | 类型 | 说明 |
|------|------|------|
| customer_id | INT PK | 客户ID |
| name | VARCHAR(50) | 姓名 |
| region | VARCHAR(20) | 所属区域 |
| city | VARCHAR(30) | 城市 |
| level | VARCHAR(10) | 等级：VIP/金牌/银牌/普通 |
| gender | VARCHAR(4) | 性别 |
| age_group | VARCHAR(10) | 年龄段：18-25/26-35/36-45/46+ |
| register_date | DATE | 注册日期 |
| total_orders | INT | 累计订单数 |
| total_amount | DECIMAL(12,2) | 累计消费金额 |

**数据量**: 20 行

### 4. campaigns（营销活动表）

| 字段 | 类型 | 说明 |
|------|------|------|
| campaign_id | INT PK | 活动ID |
| name | VARCHAR(100) | 活动名称 |
| channel | VARCHAR(20) | 渠道：线上/线下/全渠道 |
| type | VARCHAR(30) | 类型：满减/折扣/秒杀/新品首发/会员日 |
| budget | DECIMAL(10,2) | 预算 |
| actual_cost | DECIMAL(10,2) | 实际花费 |
| start_date | DATE | 开始日期 |
| end_date | DATE | 结束日期 |
| impressions | INT | 曝光量 |
| clicks | INT | 点击量 |
| conversions | INT | 转化数 |
| revenue_generated | DECIMAL(12,2) | 活动期间产生收入 |

**数据量**: 12 行

### 5. returns（退货表）

| 字段 | 类型 | 说明 |
|------|------|------|
| return_id | INT PK | 退货ID |
| order_id | INT FK | 原订单ID |
| product_id | INT FK | 商品ID |
| customer_id | INT FK | 客户ID |
| quantity | INT | 退货数量 |
| return_amount | DECIMAL(10,2) | 退款金额 |
| reason | VARCHAR(50) | 原因：质量问题/不喜欢/尺码不合适/与描述不符/物流损坏/其他 |
| return_date | DATE | 退货日期 |
| status | VARCHAR(20) | 状态：已完成/处理中/已拒绝 |

**数据量**: 15 行

### 6. daily_traffic（每日流量表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 记录ID |
| dt | DATE | 日期 |
| channel | VARCHAR(20) | 渠道：线上/线下 |
| visits | INT | 访问量 |
| unique_visitors | INT | 独立访客数 |
| orders_count | INT | 订单数 |
| revenue | DECIMAL(12,2) | 当日收入 |

**唯一约束**: (dt, channel)

**数据量**: 54 行（每月抽样3天×2渠道×9个月）

### 7. suppliers（供应商表）

| 字段 | 类型 | 说明 |
|------|------|------|
| supplier_id | INT PK | 供应商ID |
| name | VARCHAR(100) | 供应商名称 |
| category | VARCHAR(50) | 供应品类 |
| contact_person | VARCHAR(30) | 联系人 |
| region | VARCHAR(20) | 所在区域 |
| cooperation_start | DATE | 合作开始日期 |
| rating | DECIMAL(3,2) | 评分 1.00~5.00 |
| on_time_delivery_rate | DECIMAL(5,2) | 准时交货率(%) |
| total_supplied_amount | DECIMAL(14,2) | 累计供货金额 |

**数据量**: 12 行
